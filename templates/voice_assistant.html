How to allow microphone access

Chrome or Edge: Select the lock/site-controls icon beside the address, set Microphone to Allow, then reload this page. If it is already blocked, open site settings, change Microphone to Allow, and reload.

Firefox: Select the microphone icon beside the address, remove the blocked permission, reload, and choose Allow.

Android: Open Settings > Apps > your browser > Permissions > Microphone, select Allow, then reload this page.

iPhone/iPad: Open Settings > Privacy & Security > Microphone, enable your browser, then return and reload.

MSIX: Open Windows Settings > Privacy & security > Microphone, enable microphone access and desktop-app access for Isolation Bytes, then restart the app.

After changing the permission, reload this page before pressing the microphone button again. Browsers intentionally do not show a new permission prompt while a site remains blocked.
